    • In-app video playback with hardware decoding, audio and subtitle tracks, and fullscreen #80
    • Fullscreen photos and videos in the lightbox (F11)

Shipped

Highlights from each release. The full list is in the changelog.

  1. 9.11.0 October 2026
    • New People, Tags, Folders, Archive, and partner Sharing pages #235 #237 #238 #239 #236
    • Favorites: a heart button in the lightbox (or F), heart badges on thumbnails, a Favorites sidebar entry, and favorite people
    • Tags: add, create, and remove tags in the details pane, and search by tag #141
    • Trash view to restore, permanently delete, or empty trashed items #229
    • Move to trash, and edit an asset's description, date taken, and favorite status #183
    • Shared Albums, plus a Share dialog with Viewer and Editor roles
    • Rename albums and edit their descriptions
    • A header on every view, mouse back and forward buttons, and a bottom navigation bar on narrow windows
    • Public shared links with an expiry, a password, and download options
    • Server About dialog showing Immich and component versions
    • Watch folders can upload straight to the library without an album #210
    • API key file fallback when no keyring is running, and a keyring timeout so startup can't hang #215
  2. 9.10.0 October 2026
    • Works at a 360px minimum window width, with a compact masonry tier
    • Places filter on the Explore page
    • Configurable masonry grid border width and color
    • Search view stays in the sidebar
  3. 9.9.0 August 2026
    • Drag files onto the window or onto an album row to upload them
    • Drag assets out of the grid or lightbox to export the originals
    • Recently Added on Explore, with expandable sections and cached Places
  4. 9.8.0 July 2026
    • "Open With Mimick" from your file manager opens a staging window for upload
    • Video thumbnails in the staging grid
    • Selection checkboxes on grid tiles
    • Immich v3 API support
  5. 9.7.0 June 2026
    • Masonry Photos layout that keeps natural aspect ratios
    • Thumbnail quality setting: Auto, Thumbnail, Preview, or Full Size
    • Shift+Click range selection
    • Download folder prompt, batch download summary, and one conflict dialog for the whole batch
    • Clear dialogs for missing API key permissions
    • Thumbnail memory cache sized from available RAM
  6. 9.6 May 2026
    • Server statistics dialog
    • Face visibility filters in Explore
    • RAW support: fast embedded previews, optional full libraw decoding, and a decode cache
    • Lightbox decoding for JPEG XL, JPEG 2000, PSD, SVG, and more WebP and JPEG files
    • XMP sidecar uploads
    • Swipe and pinch gestures in the lightbox
    • Press animations, and an overhaul for 360px mobile screens
  7. 9.5.4 May 2026
    • Per-folder sync modes: Upload only, Download only, or Full sync #120
    • Optional two-way deletion sync, and a periodic check for remote album changes
    • Checksum dedup before upload, and rename detection
  8. 9.5.3 May 2026
    • Back navigation across library views
    • Lightbox zoom with Ctrl+scroll, pinch, and on-screen controls
    • Slide animation between lightbox images
    • Uploads in progress finish or are saved for retry when you quit
    • Faster parallel startup scan and a sharded sync index
    • Places shows every city with geotagged photos
  9. 9.5.2 May 2026
    • Right-click context menu on assets
    • Sync status icons and a video badge on thumbnails
    • Queue Inspector available from the library
    • The sync index survives clearing the cache
  10. 9.5.0 May 2026
    • Library view to browse your Immich server in the app
    • Search by metadata, OCR, Smart Search, and timeline
    • Explore page for people, places, and things
    • Albums view with album creation and album sync
Earlier releases
  1. 9.4 April 2026
    • Most settings apply as soon as you change them
    • A single summary notification per sync batch
    • One-click install with a .flatpakref file
  2. 9.1 – 9.3 April 2026
    • Every media format Immich supports, including AVIF, HEIF, JPEG XL, and MKV
    • Native notifications that work inside Flatpak, with an on/off toggle
    • Keyring storage that works inside Flatpak
  3. 9.0.0 March 2026
    • Uploads keep the correct date and timezone on the Immich timeline
    • Save settings and change watch folders without restarting
  4. 8.0.0 March 2026
    • Health dashboard and per-folder sync status
    • Quiet hours, and 1 to 10 upload workers
    • First-run setup wizard
    • Settings that work on Linux phones
  5. 7.0.0 March 2026
    • Queue Inspector with retry actions
    • Pause, resume, and Sync Now controls
    • Per-folder rules, and diagnostics export
    • Pauses on metered networks and battery power
  6. 5.0 – 6.0 March 2026
    • A startup scan catches files added while Mimick was closed
    • Run on startup, and folder access through the Flatpak portal
    • Signed Flatpak repository
  7. 3.0 – 4.0 March 2026
    • Rewritten in Rust and GTK4, shrinking the app from about 80 MB to 2 MB
    • Streaming uploads that use the same memory whatever the file size
    • Flatpak packaging
  8. 0.1 – 2.0 March 2026
    • First release, later renamed from Immich Sync to Mimick
    • LAN-first syncing that falls back to WAN
    • A retry queue that persists across restarts
