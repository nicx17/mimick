Unofficial Immich Desktop Client for Linux

Mimick

Sync local folders to Immich, browse your library, manage albums, and search assets — from a native GTK4 desktop app.

Mimick is an unofficial Immich desktop client for Linux. It backs up your photo and video folders to a self-hosted Immich server in the background, and its optional library browser lets you view, search, and manage your Immich photos from the desktop.

Install

Install from Flathub

flatpak install flathub dev.nicx.mimick

Note: Ensure you have the Flathub remote configured on your system.

Features

Automatic folder backup to Immich

Watch any folder and upload new photos and videos as they appear, with up to 10 parallel uploads and checksums that skip files already on your server.

Per-folder sync rules

Send each folder to your library, an album, or an album named after the folder. Choose Upload Only, Download Only, or Full sync, and filter by file type or size.

Reliable on any network

Failed uploads are saved and retried, Mimick switches between your home and remote server addresses, and it can pause on metered networks, on battery, or during quiet hours.

Browse your Immich library

A Photos timeline, albums, people, tags, folders, a photo map, smart and text (OCR) search, video playback, sharing, archive, and trash, in a native GTK4 window.

Made for the Linux desktop

Tray icon, start on login, drag and drop, and Open With Mimick from your file manager. The Flatpak only reads folders you pick, and your API key stays in the keyring.

Works on Linux phones

The layout adapts down to 360 pixels wide with a bottom navigation bar, so Mimick runs on Linux phones as well as desktops.

Questions

Is there an Immich desktop app for Linux?

Yes. Mimick is a free, open-source Immich desktop client for Linux. It is a community project and not made by the Immich team.

How do I back up a folder to Immich automatically?

Install Mimick from Flathub, enter your server address and an Immich API key, and add the folder under Watch Folders. New photos and videos upload in the background from then on.

Which Linux distributions does it run on?

Any distribution with Flatpak, including Fedora, Ubuntu, Debian, Arch Linux, openSUSE, Linux Mint, and Pop!_OS, on GNOME, KDE Plasma, and other desktops.

Will Mimick change or delete my local files?

Not by default. Folders start as Upload Only, which never changes local files. Download Only and Full sync add your album's photos to the folder.

Which Immich versions are supported?

Immich v3.0.0 and later.
